## 执行原则

1. 求职优先级：自动化测试 / 测试开发 > 软件测试 > 运维实施保底。
2. “AI 测试”作为项目亮点，不作为唯一岗位方向；校招岗位数量有限，不能把筹码全压在标题含 AI 的职位上。
3. 从 9 月 18 日起边学边投，不等到 10 月 10 日才投。
4. 简历只写已经做过且能讲清楚的内容；计划中的 Allure、数据库校验、UI 自动化和 CI 完成后再补进简历。
5. 每次形成有效代码或计划更新后，当天提交并推送；远端仓库仍是重要备份和求职证据。

## 安全提醒

仓库曾出现硬编码 API Key。代码已改为从环境变量读取，但 Git 历史里的旧 Key 仍应视为泄露。必须在对应平台撤销或轮换旧 Key，不能只删除代码中的字符串。
