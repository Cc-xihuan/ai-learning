# 英语计划（面向求职与技术阅读）

## 目标

到 10 月 10 日，不追求系统补完整语法，而是完成三件能直接用于求职的事：

- 能用简单英语完成 60 秒自我介绍。
- 能用 5～8 句介绍接口自动化项目。
- 能读懂测试工具 README、报错和常见英文 JD 的核心要求。

## 每天 20 分钟

1. 5 分钟复习 5 个旧表达。
2. 8 分钟朗读或跟读一小段技术材料。
3. 5 分钟脱稿说自我介绍或项目介绍的一部分。
4. 2 分钟只改最影响理解的 1～2 个错误。

英语练习记录可写在纸上、录音或任意顺手的位置，不要求每天提交 Git。

## 分阶段产出

| 日期 | 重点 | 验收 |
|---|---|---|
| 9/16～9/20 | 自我介绍与岗位词汇 | 60 秒版本不看稿说完，信息真实 |
| 9/21～9/27 | API 测试项目介绍 | 能解释 request、response、assertion、test data、report、bug |
| 9/28～10/4 | UI 自动化与排错表达 | 能用简单句说明定位元素、等待、失败原因和修复 |
| 10/5～10/10 | JD/README 阅读与模拟问答 | 10 分钟内提取一份英文 JD 的技能、职责、年限和加分项 |

## 优先掌握的句型

- I built an API test automation project using Python, pytest, and requests.
- I used YAML files to separate test data from test code.
- I wrapped common request, assertion, configuration, and logging logic.
- The project currently contains eight passing test cases.
- One problem I encountered was ..., and I fixed it by ...
- I am still improving ..., so I would not describe it as production-ready yet.

## 纠偏规则

- 先保证对方听懂，再追求复杂句型。
- 每次只修发音、语法、用词中最影响理解的两处。
- 不背与自己经历不符的“高级模板”，避免面试追问时断裂。
