# .gitignore —— 忽略文件

**级别**：🟡 会用就行 | **每个项目都应该有**

## 一句话解释
告诉 Git："这些文件/文件夹你别管，别传上去"。

## 类比
你请了管家（Git），但卧室抽屉里的日记本、保险柜密码——这些东西你不希望管家拍照存档。`.gitignore` 就是"这些东西别碰"的清单。

## 哪些东西应该忽略？
| 类型 | 例子 | 为什么 |
|------|------|--------|
| 个人笔记/对话记录 | 对话记录/ | 有个人信息 |
| 配置/密钥 | CLAUDE.md, .env | 可能含 API key |
| 系统文件 | __pycache__/, .DS_Store | 别人不需要 |
| 临时文件 | *.tmp, test.txt | 没意义 |
| 依赖包 | node_modules/, venv/ | 太大了，用 requirements.txt 代替 |

## 用法
在项目根目录新建 `.gitignore` 文件，每行写一条规则：
```
# 这是注释
文件夹名/        # 忽略整个文件夹
*.log            # 忽略所有 .log 文件
秘密文件.txt      # 忽略特定文件
```

## 注意
- `.gitignore` 只对还没被 Git 跟踪的文件生效
- 已经在 Git 里的文件需要先 `git rm --cached 文件名` 移除跟踪
- `.gitignore` 本身应该被 Git 管理（别人 clone 后也需要它）
