# git add —— 暂存文件

**级别**：🔴 必须会 | **每次提交前必用**

## 一句话解释
把文件放进"购物车"，标记它下次一起存档。

## 类比
逛超市：看中商品 → 放进购物车（git add）→ 结账（git commit）
- 放进去之前，商品还在货架上（Untracked/Unstaged）
- 放进购物车 = Git 开始盯着它（Staged，绿色）
- 结账 = 正式存档

## 常用形式
```bash
git add 文件名          # 加入单个文件
git add 文件1 文件2     # 加入多个文件
git add .               # 把当前文件夹所有新文件和改动全加入
git add *.py            # 加入所有 .py 文件
```

## 注意
- `git add` 只是标记，还没真正存档（那是 commit 的事）
- 同一个文件反复改，每次改完要重新 `git add` 才会进入购物车
- `git add .` 最常用，但初学最好先单个加，看清楚再加
