# git init —— 初始化仓库

**级别**：🟡 会用就行 | **一个项目一辈子只用一次**

## 一句话解释
告诉 Git："这个文件夹归你管了"。

## 类比
你买了个房子（文件夹），请了个管家（Git）。`git init` 就是签雇佣合同。管家会在房子里放个保险柜（`.git` 隐藏文件夹），以后所有变动他都记在里面。

## 用法
```bash
cd 你的项目文件夹
git init
```

## 发生了什么？
- 文件夹里多了个 `.git` 隐藏目录
- 所有版本历史、配置都存在这里面
- 删掉 `.git` 文件夹 = 解雇管家，仓库变回普通文件夹

## 什么时候用？
- 开始一个新项目，想用 Git 管理它
- 下载别人的项目不需要 `git init`（因为别人已经 init 过了）

## 验证是否成功
```bash
ls -la .git
```
看到一堆目录就对了。
